# Roar

**Roar Mobile App** - is an Open Source pet care app I created in my free time with the goal of providing assistance in managing your pets needs. With this app, you can easily keep track of important tasks such as vaccinations, medications, grooming, vet visits and more.

Download: [AppStore](https://apps.apple.com/de/app/roar-pet-care/id6557025787?l=en-GB) | [Google Play](https://play.google.com/store/apps/details?id=com.gaoyun.roar.android)

![Roar app screenshot](https://github.com/user-attachments/assets/e7417e81-4023-42ef-a69c-03e36858d337)

This app is designed with simplicity in mind. Hopefully, Roar can become a valuable tool for pet owners who are looking for an organized and efficient way to manage pets' daily needs.

Currently I am working solo on this project, so whenever I have some time and motivation, progress is made. Any feedback and contribution is always welcome!
